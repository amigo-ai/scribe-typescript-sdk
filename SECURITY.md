# Security

Report suspected vulnerabilities privately to **security@amigo.ai**. Include the package version, affected API or browser workflow, impact, and a synthetic reproduction. Do not include credentials, patient data, recordings, or transcripts in a public issue.

This policy covers the Scribe TypeScript package. See the [organization security policy](https://github.com/concurrence-hq/.github/blob/main/SECURITY.md) for reporting guidance across Amigo repositories.
